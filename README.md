# PyTorch Machine Learning Projects

## Overview

This repository showcases hands-on machine learning work using **PyTorch**, covering both classical ML and modern CNN deep learning. It includes two end-to-end projects designed to demonstrate model development, training, evaluation, and interpretation — reflecting practical skills expected of an ML scientist.

> Both projects are implemented as Colab notebooks, with code, commentary, and visual outputs.

---

## Included Projects

### 1. Polynomial Regression on Ice Cream Sales Data

A classic regression problem implemented in PyTorch to demonstrate model definition, training, and error analysis in a non-deep learning context.  
Key highlights:
- Synthetic data generation
- Manual gradient computation
- Model training and visualization
- Evaluation of overfitting vs. generalization

[[Open Notebook in Github](https://github.com/JeKo2022/PyTorch/blob/main/Polynomial_Regression_on_Ice_Cream_Data_using_Pytorch.ipynb) 

---

### 2. 🖼Computer Vision using PyTorch

An image classification pipeline using a convolutional neural network (CNN) trained on image data. Covers all aspects of a deep learning workflow in PyTorch.  
Key highlights:
- Data loading and normalization with `torchvision`
- CNN architecture design
- Model training and evaluation loop
- Visualization of predictions and metrics

[Open in Google Colab](https://colab.research.google.com/drive/1U7SWxkRvboGix8m20t8WzbX6ZM2cfhj-?usp=sharing)
---

## This repo demonstrates:

- **Machine learning fundamentals** (regression, loss functions, curve fitting)
- **Neural network design and training** (CNNs in PyTorch)
- **Model evaluation and visualization**
- **Clean code organization for reproducibility**
- **Fluency with PyTorch tensors, autograd, optimizers**
